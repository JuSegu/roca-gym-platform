# ROCA GYM PLATFORM

Digital platform for Roca Gym.

## Overview

ROCA GYM PLATFORM is a web platform designed to digitally connect the gym, its members and its services.

## Main Features

- Public gym website
- User authentication
- Client profiles
- Membership management
- QR gym access
- Workout routines
- Exercise tracking
- Progress tracking
- Personal records
- Gamification
- Achievements
- Leaderboards
- Community
- Online store
- Administrative dashboard

## Technology Stack

### Frontend
- Angular
- TypeScript
- Tailwind CSS

### Backend
- ASP.NET Core
- Entity Framework Core
- REST API

### Database
- PostgreSQL

### Infrastructure
- Git
- GitHub
- Cloud hosting
